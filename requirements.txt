# Create an isolated environment in this notebook's own folder, activate it,
# install, then pick it as your VS Code interpreter and notebook kernel.
#
#   python -m venv .venv
#
# Activate it. The command differs by shell, so use the one that matches yours:
#
#   Windows PowerShell:
#     .venv\Scripts\Activate.ps1
#
#   Windows Bash / Git Bash:
#     source .venv/Scripts/activate
#
#   Mac / Linux Bash:
#     source .venv/bin/activate
#
# Note the difference: on Windows the folder is Scripts/, on Mac and Linux it
# is bin/. That single letter trips up more people than anything else here.
#
# Then:
#   pip install --upgrade pip setuptools wheel
#   pip install -r requirements.txt
#
# In VS Code: Ctrl+Shift+P > "Python: Select Interpreter" > pick .venv, then
# open the notebook and select the same environment as the kernel.
