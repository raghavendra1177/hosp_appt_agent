The Agentic Hospital Appointment Booking and Medical Information System is an AI-powered healthcare application designed to provide hospital services through a conversational interface. Built using Python, Streamlit, LangGraph, and OpenAI, the system uses a multi-agent architecture to understand user requests and route them to specialized agents.

A Supervisor Agent identifies the user’s intent and directs requests to Reader, Writer, or Medical agents. The Reader Agent retrieves information such as doctors, patient details, appointments, and available slots. The Writer Agent handles operations such as booking, cancelling, and rescheduling appointments. The Medical Agent processes general health-related questions and uses information retrieval with an OpenAI model to generate clear responses.

LangGraph manages the workflow and shared application state, while Streamlit provides an interactive chat interface. The modular architecture separates data retrieval, transactional operations, and AI-based medical assistance, making the solution scalable and easier to maintain and extend.
